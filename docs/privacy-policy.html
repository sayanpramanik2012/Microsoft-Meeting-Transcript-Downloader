Privacy Policy

Effective date: August 30, 2026

Transcript Capture for Teams processes transcript information locally in the Microsoft Edge tab selected by the user. The extension does not transmit transcript information to the developer or any third party.

Scope

This policy applies to the Transcript Capture for Teams Microsoft Edge extension. The extension has one purpose: to capture an open Microsoft Teams transcript and allow the user to download it as a plain-text file.

Information accessed

After the user selects Start recorder, the extension may access:

  • Transcript text displayed in the selected Microsoft Teams tab.
  • Speaker or display names associated with transcript entries.
  • Transcript timestamps and transcription lifecycle messages.
  • Technical row indexes used to verify transcript coverage.

Meeting transcripts can contain personal or sensitive information depending on what participants discuss. The extension accesses this content only to provide its transcript-download function.

How information is used

The information is processed temporarily in the active browser tab to assemble transcript rows in the correct order, show capture completeness, and create the user-requested text download. The extension does not use transcript information for advertising, profiling, analytics, creditworthiness, or any unrelated purpose.

Storage and retention

The extension does not upload transcript information or store it in extension storage. Captured rows remain temporarily in the active tab's memory and are cleared when the recorder is stopped, the page is refreshed or navigated away from, or the tab is closed. A downloaded transcript file remains on the user's device until the user moves or deletes it.

Sharing and transmission

The extension does not sell, share, transfer, or transmit transcript information to the developer or third parties. It contains no analytics, advertising SDKs, tracking systems, external services, or remotely hosted executable code.

Browser permissions

  • activeTab: provides temporary access to the tab selected by the user after the user invokes the extension.
  • scripting: injects the recorder code included in the extension package into that selected tab.

The extension does not request persistent access to websites, browsing history, authentication information, or background tab activity.

User controls

Users control when recording starts, when auto-capture runs, whether a partial transcript is downloaded, and when the recorder stops. Users can clear temporary captured data by selecting Stop recorder, refreshing or closing the tab, or removing the extension. Users control and are responsible for any downloaded transcript files.

Security and responsible use

Local-only processing reduces data exposure, but downloaded transcript files may contain confidential information. Users should capture only transcripts they are authorized to access and protect downloaded files according to their organization’s policies and applicable law.

Changes to this policy

This policy may be updated if the extension's functionality or data practices change. The effective date above will be updated when material changes are published.
