Transcript Capture for Teams

A Microsoft Edge extension for capturing an open Microsoft Teams transcript and downloading it as a local plain-text file.

Local and user-controlled

  • The recorder runs only after you start it from the extension popup.
  • Transcript text is processed in the active Teams tab.
  • No transcript data is sent to the developer or third parties.
  • No analytics, advertising, tracking, or remote code is used.
